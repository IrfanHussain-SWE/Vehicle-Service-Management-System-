# Vehicle Management System 

A JavaFX-based Vehicle Service Management System built using Object-Oriented Programming and File Handling.

##  Student Info
Name: Irfan Hussain  
University: COMSATS University Islamabad, Wah Campus  
Program: BS Software Engineering  

## Features
- Admin, User, and Technician dashboards  
- Vehicle service booking system  
- File-based data storage  
- OOP principles (Encapsulation, Inheritance, Polymorphism)  
- JavaFX GUI interface  

##  Technologies Used
- Java  
- JavaFX  
- File Handling  
- OOP Concepts  

##  Project Structure
Organized into models, services, and UI layers for better maintainability.

##  Purpose
This project is developed for learning and academic purposes to strengthen software development skills.
